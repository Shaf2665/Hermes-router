## Why hermes-router?

Free and evaluation tiers are rate-limited. hermes-router sits between your app and a pool
of providers (Gemini, OpenRouter, Groq, and more). When one hits its limit, it tries the next
configured candidate. A request can still fail when all candidates are exhausted or unavailable.

> **Scope:** Hermes Router handles AI inference routing. Applications and agent frameworks such
> as Hall of Wisdom, Copilot, or custom clients remain responsible for tools, filesystem access,
> command execution, memory, and task orchestration.

## Quick start

```bash
curl -fsSL https://raw.githubusercontent.com/Shaf2665/Hermes-router/main/get.sh | bash
hr setup        # add a key, start the router
```

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8319/v1", api_key="YOUR_ROUTER_KEY")
resp = client.chat.completions.create(
    model="hermes-router",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)
```

On Windows or hosting in the cloud? See **[Deployment](/deployment/)**.
